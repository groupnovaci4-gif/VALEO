# Dépendances de DÉVELOPPEMENT : exécution + tests + outils de style.
#
#     pip install -r requirements-dev.txt
#
# Pourquoi ce fichier plutôt que `requirements.txt` :
#
# 1. `requirements.txt` **ne s'installe pas**. Il contient
#    `emergentintegrations==0.2.0`, hérité du builder d'origine et absent de
#    PyPI : `pip install -r requirements.txt` échoue sur cette ligne, donc rien
#    ne s'installe du tout.
# 2. Il lui manque `mongomock_motor`, dont TOUT le harnais de test dépend
#    (`tests/conftest.py`). Sans lui, `pytest` ne rate pas : il **saute** les
#    tests. On lit « skipped » et l'on croit la suite verte alors qu'elle n'a
#    rien vérifié — exactement le genre de fausse assurance que ce projet
#    combat ailleurs.
#
# `requirements.txt` est conservé tel quel (il documente l'héritage), mais
# c'est ce fichier-ci qu'il faut installer pour travailler, et
# `requirements-prod.txt` qui part dans l'image Cloud Run.

-r requirements-prod.txt
