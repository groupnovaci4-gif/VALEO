Remarques :
- Les clés marquées « existant, inchangé » sont déjà dans l'application (valeurs recopiées de
  `src/i18n/fr.ts` et `en.ts`) : rien à valider pour elles.
- Le modèle WhatsApp d'authentification de Meta impose sa propre forme (bouton « Copier le code »,
  mention de sécurité) : le texte 61 sera adapté à ce que Meta accepte.
- Les durées (10 minutes, 15 minutes) et le nombre d'essais (5) sont des propositions du
  document `PROPOSITION.md` (§2), à valider avec les textes.
